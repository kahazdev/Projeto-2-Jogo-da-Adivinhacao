Jogo de Adivinhação em Python 🎯

Um jogo simples em Python onde o jogador precisa adivinhar um número secreto entre 1 e 100. O jogo permite escolher diferentes níveis de dificuldade, oferecendo um número limitado de tentativas para acertar o número.

Funcionalidades:

Escolha de dificuldade

Fácil: 10 tentativas

Médio: 6 tentativas

Difícil: 3 tentativas

Feedback: se o chute foi maior ou menor que o número secreto.

Mensagem de vitória se o jogador acertar antes de acabar as tentativas.

Mensagem de derrota mostrando o número secreto caso o jogador não acerte.

Como jogar:

Clone ou faça o download deste repositório.

Execute o arquivo Python (python nome_do_arquivo.py).

Escolha a dificuldade desejada digitando 1, 2 ou 3.

Tente adivinhar o número secreto dentro do limite de tentativas.

python jogo_adivinhacao.py

Exemplo de execução:
Bem vindo ao jogo!
Por favor escolha uma dificuldade abaixo:

1 - Facil (10 Tentativas) 
2 - Medio (6 Tentativas) 
3 - Dificil (3 Tentativas) 

Escolha um numero: 2
Voce escolheu o Modo medio
Adivinhe o numero de 1 - 100!
Tentativa 1: 50
O Numero e maior!
Tentativa 2: 75
O Numero e menor!
...
Meus parabens voce acertou o numero secreto 63 em 4 tentativas

Python 3.x
